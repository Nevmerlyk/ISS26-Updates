# ISS26 v0.9.4-preview — PS1 graphics upload-pointer repair

**Experimental clean-original patch for ISS Pro Evolution 2 (Europe, En/Fr/De), Track 01.** This is a follow-up to v0.9.3, not a cumulative patch that requires v0.9.3 to be installed.

## Fixed at the binary level

- Repaired **36 corrupted first upload-list pointers** that pointed into texture data instead of a valid graphics command table.
- Affected resources include `DATSEL2`, `DATSEL3`, `EDT_2D`, `EDTR_2D` and 32 stadium `GDC` variants.
- The expected graphics-command signatures were checked against the clean original. Fixed pointers now resolve to those command entries in the patched resources.
- Both pointer entries were corrected where the original graphics resource requires matching pointers.
- All touched CD Mode2 Form1 EDC/ECC codes have been recalculated and validated.
- Preserves prior v0.9.3 club/national labels, player data, flags and other graphics bytes; does not touch Track 02–12 CD Audio.
- **Independent of previous installs**: the `.iss26p` applies to the clean original European Track 01. The ISS26 launcher replaces previously generated game files only after verifying SHA-256.

## Known limitations — please visually test before calling this fixed

- This update **repairs the demonstrably invalid graphics upload pointers**; it does *not* yet establish that every flag appears correctly in PS1 rendering.
- Check Bosnia, Curaçao, Cabo Verde, Algeria and DR Congo first. Report any black/mismatched flags; further sprite mapping/palette work may still be needed.
- **World-map highlights remain unchanged**; selecting Bosnia may still illuminate the old Russia region. This is a separate map-geometry/slot mapping task.
- Music, club crest art, player rosters and controller configuration have not been changed.
- If the game does not start or hangs in team selection, use the launcher's cached original or back up the previous patch files and report the screenshot/log.

No full game image, Sony BIOS or copyrighted sound data is included.

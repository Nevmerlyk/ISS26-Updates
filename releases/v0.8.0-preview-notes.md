# ISS26 v0.8.0 Preview — experimental standalone patch as updater delta

This preview contains the XOR-sector differences exported from the user-tested
**standalone ISS26 v0.8** installation, based on the **clean original European
ISS Pro Evolution 2 (SLES-03321) Track 01**.

**This is not v0.9 and is not a finished 2026 squads / correct graphics release.**
The standalone v0.8 test had known incorrect flag and club-crest mappings,
including the Cabo Verde flag and a mismatched Real Madrid crest.
This preview **retains those limitations** rather than claiming to fix them.
Real game behavior should be tested after launcher installation.

The patch is designed for the Windows launcher ISS26X01 updater and is
standalone: it must apply to clean vanilla Track 01, not to v0.5 or any
other intermediate mod. Track 02–12 CD Audio and copyrighted commercial
music are not distributed or modified by this release.

- **File to attach:** ISS26_0.8.0_preview.iss26p
- **Expected binary bytes:** 64,488 (27 changed sectors)
- **Expected SHA-256:** `4F9C4DC781934A531276C61B342A87C84858B96A691D8A6A12996A52E333AE9E`
- **Original Track 01 SHA-256:** `D9B483BDEA7774346DF437FEBF038E68CB2C4AD9932A7AD993D3C2B1F620EA44`
- **Patched Track 01 SHA-256 (user-supplied export):** `54F70287AA50CEE45989753040B53671A759036F2218DF572283244CDC19DB45`

**Automatic publication safety:** once you attach the asset and **publish** the
GitHub Release, `.github/workflows/publish-v08-preview.yml` downloads it,
checks actual SHA-256 and sector structure, confirms anonymous access, and
only then updates `latest.json` for launcher clients. Until that workflow
succeeds, users continue to receive the previous preview.

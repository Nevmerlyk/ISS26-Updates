# ISS26 v0.9.0 Preview — real PS1 graphics edits (experimental)

Experimental, standalone game patch, based on the **pristine European SLES-03321**
12-track ISS Pro Evolution 2 game. Retains all v0.8 gameplay / roster / team-name edits
**without requiring v0.8 to have been installed first**.

## Actual changes relative to v0.8

- Newly drawn 4bpp artwork for **Cabo Verde**, **Algeria**, **DR Congo**,
  **Curaçao**, and **Canada** flags, plus a recognizable **Real Madrid** crest
  replacing the mismatched old donor image.
- Dedicated previously unused graphic styles, palette updates and five replicated
  team-style lookup tables to avoid changing artwork of unaffected teams.
- Recompressed compatible European LZSS flag atlases across **38 ISO resources**,
  including `DATSEL.BIN`, `DATSEL3.BIN`, editor resources and stadium `GDC_*.BIN`.
- Correct MODE2 Form1 EDC and both ECC parity blocks for all changed CD sectors.
- Retains existing v0.8 names, existing test player edits, existing 24 clubs and
  all original 12-disc-track references; **original BIN/CUE never modified**.

## Not yet finished

This is a **preview**, NOT a finished "all 54+4 national squads and 24 club squads,
all exact flags/crests, full 2026/27 player database, kits, world map, or music" update.
Several flag/crest placeholders, incomplete rosters and original menu music remain.
Artwork correctness in live Windows/RetroArch gameplay still needs user testing.

# ISS26 v0.5.0 Preview — team names

This is a **public gameplay-testing preview**, not the promised complete 2026/27 roster/graphics overhaul and **not** an unreleased v0.9 build.

**What changes when applied to the clean European ISS Pro Evolution 2 (SLES-03321):**
- Name tables for 24 club slots, including **FC Kryvbass** and **Manchester United** (shown as `MAN UNITED`).
- The 54 national-team slots now have a proposed contemporary team-name list. **Russia's slot becomes Ghana**; **Curacao**, **Cabo Verde**, **Algeria**, **Ecuador**, **Panama**, **Senegal**, **Canada**, **Haiti**, and others appear in their respective text tables.
- The name `QAT` is used for Qatar because one original slot permits only three visible characters. `KOREA` and `BOSNIA` are abbreviated too.
- Replaces only **8 CD Mode2 Form1 sectors** and recalculates/validates sector EDC and ECC.
- Independent of prior patches: applied by ISS26 to the **unmodified original** Track 01 only, leaving Track 02–12 and their CD Audio untouched.

**Not completed:** flags, real 2026/27 squads, player ages/stats/appearance, team emblems, shirts, map highlighting, and correct region/tournament participation. Some new Africa/Asia/America labels are placed in former Europe slots and will still use old tournament membership; don't mistake this preview for a finished World Cup mod. The inaccurate 704-player-name edits from the old v0.4 are intentionally **not** included. CD Audio playback remains a separate launcher/emulator issue.

**Verification performed:** original BIN SHA-256 checked; patched image independently regenerated from `.iss26p` and full output SHA-256 matched; all 8 changed sectors pass Mode2 Form1 EDC/ECC validation. **Actual ePSXe/ISS26 gameplay of this new preview has not yet been tested.**

The launcher fetches this file from `ISS26-Updates` only if the original disc has SHA-256 `D9B483BDEA7774346DF437FEBF038E68CB2C4AD9932A7AD993D3C2B1F620EA44`. Original game files are not distributed.

If names do not display, or tournament placement is incorrect, share a screenshot from the integrated ISS26 launcher so we can fix the next standalone release.

# ISS26 v0.8 → updater format (pre-publication preparation)

This directory provides a **local** exporter for the existing tested v0.8 installation. It does not include the commercial game, game tracks, audio, emulator, or graphics assets.

## How to make a candidate patch on Windows

1. Download both [export_v08_track01.py](export_v08_track01.py) and [Export-v08.cmd](Export-v08.cmd) to the **same folder**. Python 3 is required (standard library only; no pip installs).
2. Double-click **Export-v08.cmd**.
3. Choose the **clean original European Track 01.bin** (not a previously patched copy), then the **Track 01.bin generated by your standalone v0.8 installer**. They must have the same original 496,156,752-byte length.
4. Choose `ISS26_0.8.0_preview.iss26p` as the output filename.

The exporter verifies the clean European SLES-03321 Track 01 SHA-256, writes ONLY differences as `ISS26X01` XOR-sector records, verifies every record against the original and v0.8 image, and saves `candidate-latest-v0.8.0-preview.json` containing required download URL and three SHA-256 values.

### Publication (requires verified release asset)

**Do not edit `latest.json` until the `.iss26p` has been uploaded to a public GitHub Release and independently downloaded/checked.** The launcher will start downloading this release as soon as `latest.json` is changed.

Once you have exported and tested the file, you can upload it as a GitHub Release asset to `Nevmerlyk/ISS26-Updates`, with **tag** `v0.8.0-preview` and asset name `ISS26_0.8.0_preview.iss26p`:

- [Create a release](https://github.com/Nevmerlyk/ISS26-Updates/releases/new)
- Or with authenticated GitHub CLI (`gh`):

  `gh release create v0.8.0-preview ISS26_0.8.0_preview.iss26p --repo Nevmerlyk/ISS26-Updates --prerelease --title "ISS26 v0.8.0 Preview" --notes "Experimental v0.8 Track 01 data; known flag and crest mismatches. Requires clean European BIN/CUE. CD audio is not distributed."`

After checking that the uploaded asset works anonymously, copy the content of `candidate-latest-v0.8.0-preview.json` into the repository root's `latest.json`. The current app installs updates only when the downloaded file SHA-256, original BIN SHA-256, and reconstructed Track 01 SHA-256 all match.

**Important limitations**
- The v0.8 graphical mismatches seen in gameplay are NOT fixed by this export. This is a preview, not a finished graphics or roster release.
- The exporter modifies **Track 01 only**. Audio Tracks 02–12, including the custom main-menu soundtrack from the standalone v0.8 installation, are NOT included in this public update and remain untouched.
- If the exporter rejects the original, modified file size, changed sector count, or patch size, **do not force publication**. Investigate the mismatch.
- Never upload full BIN/CUE, existing game audio, copyrighted recordings, or the full 34 MB standalone v0.8 ZIP to this public repo.

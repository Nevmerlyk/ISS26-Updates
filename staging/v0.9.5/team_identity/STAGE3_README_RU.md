# ISS26 Team Identity — Stage 3: 15 современных составов, кандидат

## Назначение

В оригинальном европейском Track 01 + опубликованном ISS26 Test 05 / Stage 2 сохранялись **15 из 17 старых составов** сборных, переименованных под ЧМ-2026. Stage 3 заменяет **330 имён** (15 × 22) в исполняемом файле `SLES_033.21` на фамилии игроков из реальных заявок ЧМ-2026.

**Не опубликовано:** это автономный патч-кандидат для исходного европейского диска, а не обновление канала `Test Game` или `Play Game`.

## Источники

- ФИФА, подтверждение официальных списков участников ЧМ-2026 (2 июня 2026): https://www.fifa.com/en/articles/fifa-world-cup-2026-squads-confirmed
- Вторичное машиночитаемое представление 26 игроков каждой команды, содержащее данные Wikipedia/ESPN: https://github.com/feuyeux/fifa-world-cup-2026/tree/main/squads (данные автора репозитория по состоянию на 29 июня 2026)
- Сохранённые индивидуальные исходные SHA, полные списки 26 игроков, выбранные 22 и четыре исключённых для каждой сборной: `staging/v0.9.5/team_identity/stage3_sources/rosters_15_fifa2026_selected.json` в ветке `development/team-identity-v095` проекта ISS26.

Важное ограничение: предложенные 22 игрока — **редакторская адаптация официальной заявки из 26 человек**, а не отдельная утверждённая FIFA «заявка из 22». Для сопоставления с существующими 22 слотами игры выбраны сильнее представленные футболисты по количеству матчей за сборную и роли; для девяти слотов потребовалось допущение по смежным игровым ролям. До финального релиза нужно проверить роли, порядок игроков и характеристики, а также изменения состава после подачи заявок.

## Безопасность и ограничения

- Исходная игра не перезаписывается.
- Полный standalone `ISS26X01` строится на локальном Stage 2 (который уже включает Test 05, Test 04, а также все остальные изменения v0.9.4).
- Используются **15** слотов: 2, 4, 10, 11, 18, 23, 26, 27, 28, 29, 31, 34, 36, 50, 52.
- Не меняются **39** остальных составов, в том числе Канада, Кабо-Верде и Украина (её регистр исправлен в Stage 2).
- Не меняются игровые характеристики, формации, поле флагов, названия в других экранах, клубы, музыка, карта мира и управление.
- Имена сохраняются в строгом старом формате **10 байт ASCII** (без диакритики). Для длинных фамилий предусмотрены сокращения и локальные инициалы для однофамильцев. Оригинальное полное написание сохранено в JSON источников.
- Босния **пока использует неверный флаг**: это отдельный нерешённый графический дефект Test 05, Stage 3 его не исправляет.
- Изменения имён могут не учитывать расстановку по позициям: у игры сохранены исходные характеристики футболистов. Требуется отдельный игровой тест.

- Всего успешно пройдено **16 автоматических тестов** для Stage 1–3. Проверка игровых меню в эмуляторе ещё не проводилась.

## Сборка

```sh
python stage3_roster_patch.py \
  --track 'ISS Pro Evolution 2 (Europe) (En,Fr,De) (Track 01).bin' \
  --baseline 'ISS26_TeamIdentity_CaseFix_Stage2_CANDIDATE.iss26p' \
  --rosters stage3_game_rosters_15.json --output stage3_results
python -m unittest -v test_team_identity_audit test_stage2_roster_case_patch test_stage3_roster_patch
```

В папке `stage3_results` находятся CSV `stage3_player_names_330.csv`, JSON с адресными предохранителями и отчёт. Патч-кандидат поставляется отдельно и предназначен **только для тестирования**.

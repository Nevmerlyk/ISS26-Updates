# ISS26 v0.9.5 — Stage 11: предматчевые названия / доказательство источника

**Статус:** завершено исследование старого архива PCSX-Redux; подготовлен новый считыватель и GPU-трассировщик. **Игровой патч не выпускался**, пользовательские файлы и сохранения не изменялись. Стабильный канал остаётся на v0.9.4, тестовый — Test 08.

## Что действительно подтверждено

Старый архив `ISS26_Explorer_20261110_125505_manual.zip` содержит отдельно сохранённые 2 МиБ оперативной памяти для экрана выбора сборных и предматчевого экрана; также имеется PCSX-Redux SaveState v5 со снимком видеопамяти. Снимки получены раньше Test 08, поэтому не доказывают нынешний результат в Test 08.

1. В RAM меню выбора в диапазоне `0x080200–0x080480` находятся текстовые имена `BOSNIA`, `N.ZEAL`, `C.VERDE`, то есть уже частично заменённые идентификаторы.
2. При переходе к предматчевому экрану эти байты заменяются программным кодом MIPS; в этом месте **нет** прежней таблицы имён.
3. В предматчевой RAM не обнаружено буквальных ASCII `Russia`, `Greece`, `Jamaica`, несмотря на то, что восстановленный напрямую из PCSX-Redux SaveState v5 кадр показывает **Ireland — Russia**.
4. В оригинальном диске буквальное `Russia` встречалось только в старых текстовых банках `ENDING`, `RESULT`, `SELECT`, `SELECT3`, `SELFORM` и `REPLAYS`; в Test08 эти вхождения отсутствуют. Сопоставление с RAM дополнительно показывает, что замена только этих банков не гарантирует правильную надпись на экране матча.
5. В одном из банков `SELECTC` сохраняются `RUS`, `GRC` и `JAM`, но рядом находятся аббревиатуры команд и имена игроков Master League. Это **не доказывает**, что предматчевый экран использует именно `SELECTC` для генерации надписи. Изменение этих кодов может повлиять на другие игровые механизмы — пока без записи.
6. Поиск строк в первых 48 МиБ оригинального диска в UTF-16-подобном представлении с шагами 2/4, либо после постоянного XOR/аддитивного преобразования байтов, не выявил **дополнительных** вариантов старых имён в исследованных режимах. Это ограниченная проверка, не исключающая более сложную кодировку, сжатие и генерацию по индексам.

**Не доказано:** откуда конкретно берутся символы предматчевого слова `Russia`: из таблицы символов, сжатого набора, специального пакета, Edit Data или предзагруженного графического источника. Нельзя называть это найденным источником. Для решения необходим одновременный снимок GP0-команд, RAM и VRAM именно текущего Test 08 во время отображения этих букв.

Дополнительная структурная проверка перебрала таблицы с постоянной длиной записей 8/10/12/16/20/24/32 байта и неизвестным однобайтовым сопоставлением символов для последовательности `RUSSIA → UKRAINE → TURKEY → GREECE`. Найдены только **две уже известные исходные ASCII-таблицы**, ни одной дополнительной таблицы простого типа. Это не исключает других способов кодирования.

## Что подготовлено

- `stage11_prematch_forensics.py`: анализ предыдущего ZIP с контрольными суммами и строгой проверкой расположения RAM/VRAM внутри SaveState v5; вывод JSON и восстановленного кадра.
- `stage11_pattern_bank_probe.cpp`: проверяет структурные последовательности названий даже при неизвестной односимвольной таблице преобразования.
- `stage11_encoded_names_probe.cpp`: быстрый безопасный поиск простейших альтернативных кодировок; **только исследовательский сканер**, не редактор ISO.
- `stage11_prematch_gpu_capture.lua`: самостоятельный read-only Lua-трассировщик для PCSX-Redux на основе API, уже использованного Academy/Explorer. После обнаружения ухода таблицы `BOSNIA`/`N.ZEAL` он записывает GPU dump и периодические снимки RAM, VRAM и экрана, позволяя установить используемые текстурные страницы и CLUT. Есть ручное включение через файл-запрос, если автоматическая диагностика произошла слишком рано.
- `test_stage11_prematch_forensics.py`: 4 автоматических теста, все прошли.
- `stage11_results/stage11_report.json` и `stage11_results/prematch_framebuffer_reference.png`: неоспоримые результаты из старой сессии.

## Повторный запуск проверки старого архива

```
python stage11_prematch_forensics.py --archive ISS26_Explorer_20261110_125505_manual.zip --out stage11_results
python -m unittest -v test_stage11_prematch_forensics
```

## Использование нового Lua-инструмента

Нужна PCSX-Redux, загрузка дополнительного Lua-скрипта и заранее существующий каталог записи. Скрипт **не встроен в текущий APK/Launcher и не загружается в него автоматически**.

- Задать для процесса эмулятора переменную окружения `ISS26_PREMATCH_CAPTURE_DIR` с путём к существующей папке для записи (или использовать уже существующую `ISS26_EXPLORER_SESSION_DIR` Академии).
- Загрузить `stage11_prematch_gpu_capture.lua` штатным способом PCSX-Redux. Открыть выбор сборных, начать матч. После исчезновения имени `BOSNIA` из участка RAM скрипт начнёт запись. По умолчанию 900 кадров, максимум 1800 (настраивается `ISS26_PREMATCH_CAPTURE_FRAMES`).
- В качестве запасного способа, находясь прямо на предматчевом экране, создать пустой файл `prematch_now.request` в указанной папке. Скрипт сам удалит его после обработки и начнёт дополнительную запись.
- Собирать совместно `.gpd`, `.vram`, `*_RAM.bin`, `.screen.raw` и `stage11_trace_events.csv`. **Не публиковать весь RAM/VRAM в открытом репозитории**: эти дампы могут содержать исходные игровые данные или сведения с карты памяти.

## Следующая инженерная цель

В трассе найти GP0-команды текстовых примитивов, используемые страницы текстур и адреса RAM, которые отвечают за слово Russia. Подтвердить, что найденный ресурс принадлежит **предматчевым меткам**, после чего сделать узкий независимый `.iss26p` с проверкой на чистом диске. Стадионные `GDC_*` **не изменять**: Test 07 продемонстрировал графическую регрессию, а Test 08 этого кода не содержит.

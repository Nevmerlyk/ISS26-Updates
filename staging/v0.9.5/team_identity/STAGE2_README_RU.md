# ISS26 v0.9.5 — Team Identity, этап 2: составы и регистр имён

## Доказано на исходном европейском Track 01 + официальном ISS26 Test 05

В исполняемом файле `SLES_033.21` (ISO LBA 24, длина 339 968 байт) определён текстовый банк национальных составов:

- Начало ресурса: **смещение 293 204**.
- 54 сборные × 22 футболиста = **1 188** строк.
- Каждое имя занимает **10 байт**, включая потенциальные нулевые окончания.
- Порядок блоков обратен ID сборных: блок слота №53 начинается с 293 204, №24 — с 299 584, №0 — с 304 864.
- Формула: `offset = 293204 + (53 - team_slot)*220 + player_index*10`.

Полный перечень 1 188 текущих игроков и их прежних версий: `stage2_results/national_rosters_1188.csv`.

### Подтверждённые дефекты

1. **Украина**, слот №24 — 22 имени только заглавными буквами.
2. **Кабо-Верде**, слот №53 — 22 имени только заглавными буквами.
3. **Катар**, слот №2 — в `SELECT3.BIN` осталось `U.A.E.` вместо `Qatar`.
4. **15 из 17 заменённых сборных** по-прежнему используют оригинальные имена футболистов 2001 года; обновлены только Канада и Кабо-Верде. Исправление регистра не решает проблему устаревших составов.

### Что исправлено в локальном кандидате

- Переведены в нормальный регистр **44 имени** (22 Украины + 22 Кабо-Верде) с сохранением тех же букв, точек, пробелов, длины и позиций.
- Исправлено имя `U.A.E.` → `Qatar` в дополнительной текстовой таблице `SELECT3.BIN`.
- Не изменены коды сборных `RUS`, `GRC`, `JAM` и т.п. — их машинное назначение ещё не доказано.
- Не изменены большие флаги, малые флаги, имена других 52 сборных и составы других команд.
- Патч кандидат самостоятельный для **чистого оригинального Track 01**; включает весь текущий Test 05, а не требует установки промежуточных патчей.
